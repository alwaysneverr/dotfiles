# Han Sooyoung GRUB theme, after her "novel" lock screen: full-screen art (grub.jpg, copied in as
# background.jpg), the menu on a frosted panel at the left, the selected entry marked by a ruled line.
#
# GRUB draws text without anti-aliasing, so:
# - the menu uses a bitmap book face: New Century Schoolbook from the X11 100dpi fonts, hand-drawn
#   for pixels, so it stays crisp where outline fonts turn jagged;
# - the hint line is a pre-rendered, smooth image (hint.png, TeX Gyre Schola, the same face's
#   outline cousin). The menu entries and the countdown change at boot, so they stay text.
#
# Rebuild the fonts (pacman -S xorg-fonts-100dpi; the pixel size must match the bitmap exactly):
#   grub-mkfont -n "HSY Book" -s 25 -o book-25.pf2      /usr/share/fonts/100dpi/ncenR18.pcf.gz
#   grub-mkfont -n "HSY Book" -s 25 -o book-bold-25.pf2 /usr/share/fonts/100dpi/ncenB18.pcf.gz
#   grub-mkfont -n "HSY Book" -s 17 -o book-17.pf2      /usr/share/fonts/100dpi/ncenR12.pcf.gz
