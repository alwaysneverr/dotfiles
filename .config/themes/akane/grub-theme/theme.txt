# Akane Kurokawa GRUB theme, after her "stage" lock screen: the art fills the screen, and the menu sits
# on a lit card at the left (indigo, teal border and glow, like the lock's framed clip), with the
# selected entry in a teal pill like the lock's password field.
#
# GRUB draws text without anti-aliasing, so:
# - menu and countdown use a bitmap sans (Lucida Sans from the X11 100dpi fonts, drawn for pixels);
# - the card, her star, name and the hint line are one smooth pre-rendered image (card.png).
#
# Rebuild the fonts (pacman -S xorg-fonts-100dpi; the pixel size must match the bitmap exactly):
#   grub-mkfont -n "AK Sans" -s 20 -o ak-sans-20.pf2      /usr/share/fonts/100dpi/luRS14.pcf.gz
#   grub-mkfont -n "AK Sans" -s 20 -o ak-sans-bold-20.pf2 /usr/share/fonts/100dpi/luBS14.pcf.gz
#   grub-mkfont -n "AK Sans" -s 17 -o ak-sans-17.pf2      /usr/share/fonts/100dpi/luRS12.pcf.gz
